# Projeto de landing page para App Finess

Página com fundo branco e fonto Roboto como principal
Objetivo é ter uma landin page clean, branca e sofissticada.

## Seção HEADER:

logo no canto esquerdo
- A logo é um JF em um circulo (feito com CSS)
- O fundo do circulo é VERDE ESCURO

Botão de download no canto direito
- fundo verde, cor branca
- borda arredondada

## Seção HERO:

A hero dave ter altura 90vh, divido em 3 áreas horizontais:

Esquerda:
Apenas a headline, sem ser grande demais, sem destaque(o destaque é o print do app no meio).
"o app perfeito para acompanha sua vida fitness"

Centro:
Em destaque a imagem PRIMEIRO-PROJETO/img/print_1.png que é um printo do app.

Direita:
Uma lista de pontos-chave sobre o app:
- 💓 Saúde
- 🏃 Exercio
- 🤼‍♂️ Amigos

##Seção de Funcionalidades:

Vão ser usadas as imagens PRIMEIRO-PROJETO/img/print_2.png, PRIMEIRO-PROJETO/img/print_3.png, PRIMEIRO-PROJETO/img/print_4.png que serão exibidas da seguinte forma:
- print / texto
- texto / print
- print / texto

ou seja, irá alternar entre o print na esquerda e um texto explicativo na direita, vice-versa.

Descrição breve de cada print para você gerar um texto adequado:
- print_2.png =  Contagem de calorias 
- print_3.png = exercicios especificos (corrida, musculação, etc)
- print_4.png = Compartilhamento com amigos

## Seção de acompanhamento diário:

Painel interativo para o usuário acompanhar metas e atividades do dia:
- passos, com progresso em relação à meta diária de 8.000
- água, registrando copos de 250 ml em relação à meta de 2.000 ml
- exercícios, com tipo e duração registrados em uma lista do dia

Os registros são salvos no navegador e reiniciados quando começa um novo dia.

##Seção de CTA (call-to-action):
Botão grande de download com um texto abaixo dele destacando:
"totalmente fratuito"

##Seção de RODAPÉ:
Apenas com o texto "Todos os direitos reservados"
