# JF Fitness

Landing page do JF Fitness com um painel interativo para acompanhar passos,
consumo de água e exercícios do dia. Os registros são armazenados localmente no
navegador e reiniciados em um novo dia.

## Executar localmente

Abra `index.html` no navegador. O projeto não requer instalação de dependências
ou etapa de build.

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`. Cada atualização
na branch executa o workflow de publicação.
